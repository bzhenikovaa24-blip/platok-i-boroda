# Платок и Борода

![иконка](client/icon.png)

Кооперативный платформер на двоих за одной клавиатурой.
Героиня — девочка в платке и розовой кофте, герой — бородач в кепке. Каждому безопасна
только своя жижа, а пройти храм можно лишь вместе.

**Играть в браузере:** https://bzhenikovaa24-blip.github.io/platok-i-boroda/ (без сервера, рекорды хранятся в браузере).

## Запуск на Windows

Игра работает как веб-приложение: двойной клик по ярлыку «Платок и Борода» на рабочем столе
(или по `launch.vbs` в папке) запускает сервер NestJS без окна консоли и открывает игру
в отдельном окне Microsoft Edge, без адресной строки, как обычную программу.

- Первый запуск (если ещё нет `server/node_modules`) идёт через `start.bat` в консоли:
  скачиваются зависимости (нужны Node.js LTS и интернет, 1–2 минуты).
- Сервер сам выключается примерно через 45 секунд после закрытия окна игры, а кнопка
  «Выйти из игры» в меню выключает его сразу.
- Игра — PWA: в браузере появляется кнопка «Установить приложение», после установки игра
  открывается из меню «Пуск» и работает даже без сервера (рекорды тогда хранятся в браузере).
- `start.bat` — запуск с консолью и логами (удобно для разработки).
- Логи режима приложения пишутся в `data/server.log` и `data/build.log`.
- Если Node.js нет, ярлык откроет офлайн-версию `client/index.html`.

## Управление

| | Девочка в платке | Бородач в кепке |
|---|---|---|
| Ходить | `A` / `D` | `←` / `→` |
| Прыжок | `W` | `↑` |
| Рычаг | `S` | `↓` |

`R` — заново, `Esc` — пауза, `M` — звук.

Геймпады: первый управляет девочкой, второй бородачом (стик или крестовина — ходьба, A — прыжок,
B или X — рычаг, Start — пауза). В «Настройках»: громкость, музыка, тряска экрана, качество
графики (быстрый режим для слабых ноутбуков) и полноэкранный режим.

Правила: розовая жижа безопасна для девочки, золотая — для бородача, зелёный яд убивает обоих.
Розовые кристаллы собирает девочка, золотые — бородач. В меню «Образы» можно выбрать раскраску каждому герою (по 6 вариантов), выбор запоминается.
Кнопки работают, пока на них кто-то
стоит (или ящик). Уровень пройден, когда оба стоят у своих дверей.
Звёзды: 1 за прохождение, +1 за все кристаллы, +1 если уложились в норматив времени.

## Что умеет игра

- **Кампания** — 35 уровней в двух главах: «Храм двоих» (1–30) и «Подземье» (31–35) со льдом,
  вентиляторами, порталами и тёмными уровнями. Каждый 5-й уровень — босс.
- **Сюжет** — сценки с диалогами перед главами и после боссов (пересмотреть: кнопка «Сюжет»).
- **Гонки** — 5 трасс на разделённом экране, призрак лучшего заезда.
- **Редактор уровней** — рисуй карту мышкой (стены, лёд, жижи, кристаллы, ящики, ветер, порталы,
  рычаги с воротами), проверяй кнопкой «Тест», сохраняй в базу и делись 6-значным кодом.
- **По сети** — два ноутбука в одной Wi-Fi сети: хозяин играет за девочку, гость за бородача.
- **Профиль** — регистрация и вход; прогресс и рекорды сохраняются за игроком.
- **Магазин образов** — новые расцветки покупаются за собранные кристаллы.
- **Достижения, настройки, геймпады, музыка, полноэкранный режим, PWA-установка.**

## Боссы и гонки

- Каждый 5-й уровень (5, 10, 15, 20, 25, 30, 35) — босс: длинный уровень с контрольными точками
  и ареной в конце.
- В гонках экран делится пополам: сверху дорожка девочки, снизу бородача, трассы одинаковые,
  жижи зеркальные. Кто первым коснётся флага — победил. Счёт побед хранится в базе.
- Достижения — 20 наград за прохождения, боссов, гонки и упорство.

## Для учёбы и разработки

| `test.bat` | автотесты API (Jest + Supertest, `server/test/app.e2e-spec.ts`, 16 тестов) |
| `tests/postman/…postman_collection.json` | коллекция Postman: 22 запроса с проверками, переменные заполняются сами |
| `analytics.bat` | Python-аналитика: графики смертей, времени, популярности уровней, гонок (`data/analytics.html`) |
| `report.bat` | текстовый/HTML-отчёт по базе |
| `build-exe.bat` | сборка настольной версии на Electron: `desktop/dist/PlatokIBoroda-win32-x64/PlatokIBoroda.exe` |
| `Dockerfile`, `docker-compose.yml` | запуск в Docker: `docker compose up --build`, данные в томе `game-data` |

## Что внутри

```
launch.vbs           запуск как приложение: сервер без консоли + окно Edge
app.bat              то, что запускает launch.vbs (сборка и сервер в фоне)
start.bat            запуск с консолью: npm install → сборка → сервер → браузер
report.bat           HTML-отчёт по статистике из базы (Python)
client/              игра: HTML + CSS + JavaScript (Canvas 2D, WebAudio, Gamepad API)
  manifest.webmanifest, sw.js   PWA: установка и офлайн-кэш
server/              бэкенд на NestJS (TypeScript)
  src/database/      DatabaseService: SQLite через sql.js, миграции, сохранение в файл
  src/levels/        уровни: загрузка из shared/levels.json в БД, REST
  src/teams/         команды игроков и их прогресс
  src/runs/          прохождения и таблица рекордов
  src/races/         результаты гонок и счёт побед
  src/app/           режим приложения: heartbeat, автовыключение, кнопка «Выйти», адреса для сети
  src/auth/          регистрация, вход (scrypt + подписанный токен), профиль, AuthGuard
  src/custom-levels/ уровни из редактора: проверка карты, короткие коды
  src/net/           WebSocket-шлюз для игры по сети (комнаты по 4-значному коду)
  */dto/             DTO с class-validator — проверка всех входящих данных
server/test/         e2e-тесты API
  src/stats/         общая статистика и health-check
desktop/             Electron-обёртка для .exe
shared/levels.json   описание 35 уровней кампании и 5 гоночных трасс
icon.ico             иконка игры
tools/               Python-утилиты
data/game.db         база SQLite (создаётся при первом запуске)
```

### База данных (SQLite)

- `teams` — команды (название уникально без учёта регистра);
- `levels` — карты уровней, подсказки, норматив времени, объекты (JSON);
- `runs` — каждое прохождение: время, кристаллы, смерти, звёзды;
- `races` — каждая гонка: победитель и время каждого героя;
- `custom_levels` — уровни из редактора с кодом и счётчиком игр;
- `users` — игроки: логин, хэш пароля (scrypt с солью), связанная команда.

Таблица рекордов строится оконной функцией `ROW_NUMBER()`: лучшая попытка каждой команды на уровне.

### Python-утилиты

```
python tools/build_levels.py          сгенерировать shared/levels.json и client/levels.js
python tools/level_tool.py validate   проверить уровни (размеры, старты, двери, триггеры)
python tools/level_tool.py preview 3  нарисовать уровень 3 в консоли цветом
python tools/level_tool.py report     статистика из data/game.db
python tools/level_tool.py report --html   то же в data/report.html
```

Уровни 1–4 нарисованы вручную в `tools/build_levels.py`, остальные собирает генератор
`tools/campaign.py` из испытаний (жижи, яд шириной в 3 клетки, островки, рычаги и ворота,
ящик с кнопкой, плиты над ядом). С каждым уровнем испытаний больше, они сложнее, плиты быстрее.
Уровни-боссы — это длинные уровни шириной в три экрана (камера едет за героями)
с контрольными точками. Точка срабатывает, когда до неё дошли оба героя; после смерти оба
появляются у последней точки, собранные кристаллы сохраняются. В конце — арена со стражем:
он роняет капли (розовые опасны для бородача, золотые для девочки, зелёные для обоих),
а бьют его, одновременно встав каждый на свою руну. Три удара (у двух последних боссов — четыре),
и ворота к дверям открываются.

Гоночные трассы собирает `tools/race.py`.

Генератор пишет для каждого уровня пошаговое решение в `tools/solutions.json`: по нему бот
проходит уровень на настоящем движке игры, так проверено, что все уровни и трассы проходимы
и все кристаллы собираются. Нормативы времени лежат в `tools/pars.json`.

Уровни описаны в `tools/build_levels.py` кодом (`fill`, `put`, `obj`). Поменял уровень —
запусти `build_levels.py`, потом перезапусти сервер или вызови `POST /api/levels/reload`.

Обозначения карты: `#` стена, `P` розовая жижа, `G` золотая, `X` яд, `a`/`b` старт,
`A`/`B` двери, `p`/`g` кристаллы. Объекты: `button`, `lever`, `gate`, `lift`, `platform`, `box`,
`checkpoint`, `boss`, `finish`.
