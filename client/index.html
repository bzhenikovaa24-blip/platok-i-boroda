Гонки

Экран делится пополам: сверху дорожка девочки, снизу — бородача. Трасса у обоих одинаковая, только жижи зеркальные. Кто первым коснётся флага — победил. Упал — вернёшься к своей контрольной точке. Полупрозрачный призрак повторяет ваш лучший заезд на трассе.

Профиль

Профили работают, когда игра запущена с сервером (ярлык на рабочем столе). Сейчас игра в офлайн-режиме.

Войди, чтобы прогресс, рекорды и гонки сохранялись за тобой на любом компьютере с этим сервером.

Игра по сети

Игра по сети работает только с сервером: запусти игру ярлыком на рабочем столе.

Два ноутбука в одной Wi-Fi сети. На одном игра запущена ярлыком — он хозяин и играет за девочку. Второй открывает в браузере адрес: …, жмёт «По сети» и вводит код комнаты. Он играет за бородача. Windows может спросить разрешение для сети — нажми «Разрешить».

Геймпады

Подключи один или два геймпада: первый управляет девочкой, второй бородачом. Стик или крестовина — ходьба, A — прыжок, B или X — рычаг, Start — пауза. Клавиатура при этом тоже работает.

Как играть

Девочка в платке

A D — ходить, W — прыжок, S — рычаг

Розовая жижа ей нипочём. Золотая — смертельна.

Бородач в кепке

← → — ходить, ↑ — прыжок, ↓ — рычаг

Золотая жижа — его стихия. Розовая — смертельна.

  • Зелёный яд опасен для обоих.
  • Розовые кристаллы собирает девочка, золотые — бородач.
  • Кнопки работают, пока на них кто-то стоит (или ящик).
  • Уровень пройден, когда оба стоят у своих дверей.
  • R — заново, Esc — пауза, M — звук.
  • Можно играть на геймпадах: первый — девочка, второй — бородач (A — прыжок, B — рычаг).
